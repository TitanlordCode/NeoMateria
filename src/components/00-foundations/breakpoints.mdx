NeoMateria's responsive system is built on four mobile-first breakpoints. Use standard `@media` queries in your own projects — the PostCSS mixins are for contributors building components inside the library.

## JavaScript / TypeScript

The breakpoint values and media query strings are exported from the library for use in `matchMedia`, resize logic, or dynamic styles.

```ts
import { breakpoints, mediaQueries } from 'neo-materia'

// Pixel values
breakpoints.md // 768

// Ready-to-use media query strings
const isDesktop = window.matchMedia(mediaQueries.lg).matches

// With a ResizeObserver or reactive ref
const mediaQueryList = window.matchMedia(mediaQueries.md)
```

Visual regression tests run against five fixed viewports. The set was chosen to cover every CSS breakpoint transition — no two adjacent viewports share the same active breakpoint set.

By default, every snapshot story runs at all five viewports. Use `parameters.snapshot.viewports` in a story's `meta` or individual story object to restrict which viewports run for that story group:

```ts
// In meta — applies to all stories in the file
parameters: {
  snapshot: { viewports: ['sm', 'xl'] },
}

// In a single story — overrides the meta default
export const AllColors: Story = {
  parameters: {
    snapshot: { viewports: ['sm', 'xl'] },
  },
}
```

Use `diffThreshold` to allow a small percentage of pixels to differ — useful for stories whose snapshots contain text rendered with system fonts, where sub-pixel hinting can vary slightly between Chromium instances. The value is a ratio (e.g. `0.001` = 0.1% of total pixels). Omit it entirely for strict pixel-exact comparison, which is the default for all stories.

```ts
parameters: {
  snapshot: { viewports: ['sm', 'xl'], diffThreshold: 0.001 },
}
```

**Default viewport sets by component tier:**

| Tier | Default viewports | Reason |
|---|---|---|
| Atoms | `sm`, `lg`, `xl` | Font and padding scale at bp-sm and bp-lg; no grid changes |
| Molecules | `sm`, `md`, `lg`, `xl` | Responsive layout changes; 2xl adds no new information |
| Organisms | all 5 | Genuine layout changes at every breakpoint + overflow check |
| AllColors / OnDark / RTL (atoms & molecules) | `sm`, `xl` | Only color/theme or direction differs — no layout change |

## CSS mixin — for library contributors only

```css
.MyComponent {
  flex-direction: column;

  @mixin bp-md {
    flex-direction: row;
  }

  @mixin bp-lg {
    gap: 48px;
  }
}
```

Each mixin expands to a `@media (width >= Npx)` rule. Mobile-first: styles outside a mixin apply to all viewport sizes, and each mixin overrides upward from its threshold.

This requires PostCSS with `postcss-mixins` configured to load NeoMateria's mixin files. It is **not** available to library consumers unless they replicate that PostCSS setup. Use standard `@media` queries instead:

```css
.MyElement {
  flex-direction: column;
}

@media (width >= 768px) {
  .MyElement {
    flex-direction: row;
  }
}
```
