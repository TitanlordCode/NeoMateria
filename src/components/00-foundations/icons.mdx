<Title>Default Icons</Title>

NeoMateria ships a small set of ready-to-use icons. They are plain SVG VNodes — pass them directly into the default slot of `NeoIcon` or any icon slot.

```ts
import { InfoIcon, ChevronDownIcon, CloseIcon } from 'neomateria'
```

```vue
<!-- Inside NeoIcon for sizing and color control -->
<NeoIcon color="blue">{{ InfoIcon }}</NeoIcon>

<!-- Directly into a component icon slot -->
<NeoCallout color="blue">
  <template #icon>{{ InfoIcon }}</template>
  Message text.
</NeoCallout>
```

## Adding icons (contributors)

The single source of truth for all icon SVG markup is `src/components/01-atoms/Icon/iconStrings.ts`. Each icon is defined there as a plain string export, for example `addIconSvg`.

`defaultIcons.tsx` derives VNodes from those strings via Vue's `createStaticVNode` — so adding an icon means adding the string once, and the VNode is created automatically.

`parameters.docs.source.code` in story files always requires a plain string. Import the string export from `.storybook/utils/iconSnippets` (which re-exports from `iconStrings.ts`) and interpolate it into the template literal:

```ts
import { addIconSvg } from '../../../../.storybook/utils/iconSnippets'

parameters: {
  docs: { source: { code: `<NeoIconButton ariaLabel="Add">\n  ${addIconSvg}\n</NeoIconButton>` } }
}
```

For the VNode used in the render function, import from `defaultIcons`:

```ts
import { AddIcon } from '@/components/01-atoms/Icon/defaultIcons'

render: () => <NeoIconButton ariaLabel="Add">{AddIcon}</NeoIconButton>
```
