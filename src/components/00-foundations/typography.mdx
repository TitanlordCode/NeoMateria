## Font family

NeoMateria ships with a system font stack by default — no Google Fonts import, no external requests. All components inherit font from the document root, so swapping the font is a single CSS variable change.

### Default

```css
:root {
  --neo-fontFamily-base: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto,
    'Helvetica Neue', Arial, sans-serif;
}
```

The variable is applied to `:root` in the delivered CSS, so every NeoMateria component inherits it automatically.

### Using a custom font

Import your font (Google Fonts, self-hosted, or system), then override `--neo-fontFamily-base`:

```css
/* main.css — loaded before NeoMateria components render */
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap');

:root {
  --neo-fontFamily-base: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI',
    Roboto, 'Helvetica Neue', Arial, sans-serif;
}
```

Set it on `:root` to apply document-wide, or on any container element — paired with `font-family: var(--neo-fontFamily-base)` — to scope it to a subtree.

## Text overflow strategies

NeoMateria uses a three-strategy system for handling text that exceeds its container. Every text element applies **at least one strategy** depending on whether the element is UI chrome (navigation, labels) or content (cards, panels).

---

## Strategy 1 — Single-line truncation

**When to use:** UI chrome elements where wrapping would break layout — navigation labels, table cells, compact list items.

```css
.Element-label {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

**Applied to:** `NeoNavItem` labels.

			borderRadius: '8px',

			padding: '8px',
		}}
	>
		{[

## Strategy 2 — Line clamp

**When to use:** Content previews where the element has a fixed role — card titles, card descriptions, panel titles.

```css
.Element-title {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: var(--Element-sizing-titleClamp);
  line-clamp: var(--Element-sizing-titleClamp);
  overflow: hidden;
}
```

The clamp count is exposed as a CSS variable so consumers can override it without a prop:

```css
.my-context .NeoCard {
  --NeoCard-sizing-titleClamp: 1;
  --NeoCard-sizing-descriptionClamp: 2;
}
```

**Applied to:** `NeoCard` title (2 lines), `NeoCard` description (3 lines), `NeoProgressPanel` title (2 lines).

<div

		gap: '24px',

## Strategy 3 — Overflow wrap + hyphenation

**When to use:** All multi-line text as a baseline safety net. Prevents a single long word or URL from causing horizontal overflow without restricting line count.

```css
.Element {
  hyphens: auto;
  overflow-wrap: break-word;
}
```

**`hyphens: auto` requires a `lang` attribute** on the element or an ancestor — typically `<html lang="de">`. Without it the property has no effect and `overflow-wrap` acts as a fallback. This is by design: the component sets the capability, the app provides the language context.

```html
<!-- app root — enables hyphenation for all components -->
<html lang="de">

<!-- or per-section -->
<section lang="de">
  <NeoCard title="Donaudampfschifffahrtsgesellschaft" ... />
</section>
```

**Applied to:** `NeoButton`, `NeoCard`, `NeoProgressPanel`, and all other multi-line text elements as a baseline.

## Line clamp — `clamp` prop and CSS mixin

### Consumer API — `clamp` prop

`NeoText` and all four `NeoHeadline` variants accept a `clamp` prop. Pass any positive integer to limit the element to that many lines.

```html
<!-- NeoHeadlinePrimary.vue -->
<NeoHeadlinePrimary :clamp="3">Long headline that will be cut after three lines…</NeoHeadlinePrimary>

<!-- NeoText.vue -->
<NeoText :clamp="2">Long body copy that will be cut after two lines…</NeoText>
```

The prop adds the `--clamped` modifier class and sets `--ComponentName-sizing-clamp` as an inline style. Internally this drives `-webkit-line-clamp` and the standard `line-clamp` property.

### CSS variable override (no prop needed)

Because the clamp count is a CSS variable, you can override it in context without touching the component:

```css
.my-context .NeoText {
  --NeoText-sizing-clamp: 4;
}
```

### CSS mixin — for library contributors only

```css
.MyComponent-title {
  @mixin line-clamp 3;
}
```

Expands to the full `display: -webkit-box` block. Requires PostCSS with `postcss-mixins` configured to load NeoMateria's mixin files — **not available to library consumers**. Use the `clamp` prop or the CSS variable override instead.

## Combining strategies

Strategies are not mutually exclusive. `NeoProgressPanel` subtitle uses all three: clamped to 1 line, truncated with ellipsis, and wrapped on long words:

```css
.NeoProgressPanel-subtitle {
  hyphens: auto;
  overflow: hidden;
  overflow-wrap: break-word;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```
