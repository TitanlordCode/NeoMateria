## JavaScript / TypeScript

The breakpoint values and media query strings are exported from the library for use in `matchMedia`, resize logic, or dynamic styles.

```ts
import { breakpoints, mediaQueries } from 'neo-materia'

// Pixel values
breakpoints.md // 768

// Ready-to-use media query strings
const isDesktop = window.matchMedia(mediaQueries.lg).matches

// With a ResizeObserver or reactive ref
const mediaQueryList = window.matchMedia(mediaQueries.md)
```

## CSS mixin — for library contributors only

```css
.MyComponent {
  flex-direction: column;

  @mixin bp-md {
    flex-direction: row;
  }

  @mixin bp-lg {
    gap: 48px;
  }
}
```

Each mixin expands to a `@media (width >= Npx)` rule. Mobile-first: styles outside a mixin apply to all viewport sizes, and each mixin overrides upward from its threshold.

This requires PostCSS with `postcss-mixins` configured to load NeoMateria's mixin files. It is **not** available to library consumers unless they replicate that PostCSS setup. Use standard `@media` queries instead:

```css
.MyElement {
  flex-direction: column;
}

@media (width >= 768px) {
  .MyElement {
    flex-direction: row;
  }
}
```

## How Theme Colors Work

When you apply a color to a component (e.g., `color="blue"`), the theme system provides:

- **`--neo-theme-color`**: Main background color
- **`--neo-theme-colorText`**: Text color for use ON the main color (auto-selected for WCAG AA compliance)
- **`--neo-theme-colorAccent`**: Subtle accent color (shade 200) for focus states
- **`--neo-theme-colorAccessible`**: Accessible color for text/borders ON page backgrounds

### Accessibility Strategy

**Light Mode (on white/light backgrounds):**
- Most colors use **white text** on a darker shade (automatically selected starting from 500)
- **Yellow, Amber, Orange** use **black text** on shade 500 for proper contrast

**Dark Mode (on black/dark backgrounds):**
- All colors use **black text** on a lighter shade (automatically selected starting from 500)

All color combinations are tested to meet **WCAG AA** contrast requirements (4.5:1 for normal text).

## Strategy 3 — Overflow wrap + hyphenation

**When to use:** All multi-line text as a baseline safety net. Prevents a single long word or URL from causing horizontal overflow without restricting line count.

```css
.Element {
  hyphens: auto;
  overflow-wrap: break-word;
}
```

**`hyphens: auto` requires a `lang` attribute** on the element or an ancestor — typically `<html lang="de">`. Without it the property has no effect and `overflow-wrap` acts as a fallback. This is by design: the component sets the capability, the app provides the language context.

```html
<!-- app root — enables hyphenation for all components -->
<html lang="de">

<!-- or per-section -->
<section lang="de">
  <NeoCard title="Donaudampfschifffahrtsgesellschaft" ... />
</section>
```

**Applied to:** `NeoButton`, `NeoCard`, `NeoProgressPanel`, and all other multi-line text elements as a baseline.

## Line clamp — `clamp` prop and CSS mixin

### Consumer API — `clamp` prop

`NeoText` and all four `NeoHeadline` variants accept a `clamp` prop. Pass any positive integer to limit the element to that many lines.

```html
<!-- NeoHeadlinePrimary.vue -->
<NeoHeadlinePrimary :clamp="3">Long headline that will be cut after three lines…</NeoHeadlinePrimary>

<!-- NeoText.vue -->
<NeoText :clamp="2">Long body copy that will be cut after two lines…</NeoText>
```

The prop adds the `--clamped` modifier class and sets `--ComponentName-sizing-clamp` as an inline style. Internally this drives `-webkit-line-clamp` and the standard `line-clamp` property.

### CSS variable override (no prop needed)

Because the clamp count is a CSS variable, you can override it in context without touching the component:

```css
.my-context .NeoText {
  --NeoText-sizing-clamp: 4;
}
```

### CSS mixin — for library contributors only

```css
.MyComponent-title {
  @mixin line-clamp 3;
}
```

Expands to the full `display: -webkit-box` block. Requires PostCSS with `postcss-mixins` configured to load NeoMateria's mixin files — **not available to library consumers**. Use the `clamp` prop or the CSS variable override instead.

---

## Combining strategies

Strategies are not mutually exclusive. `NeoProgressPanel` subtitle uses all three: clamped to 1 line, truncated with ellipsis, and wrapped on long words:

```css
.NeoProgressPanel-subtitle {
  hyphens: auto;
  overflow: hidden;
  overflow-wrap: break-word;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```
